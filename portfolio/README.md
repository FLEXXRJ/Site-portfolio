# Portfolio — Ryan Jaspart

Site vitrine one-page pour présenter mes services de développement web freelance.

## Stack

- HTML5
- CSS3 (Flexbox, responsive)
- JavaScript (validation formulaire, menu mobile, scroll fluide)

## Fichiers

- `index.html` — structure
- `portfolio.css` — styles
- `portfolio.js` — interactions
- `favicon.svg` — icône du site
- `Portfolio.png` — capture de ce portfolio
- `pain-dore.PNG` — capture du projet boulangerie

## Déploiement Netlify (portfolio)

1. Va sur [netlify.com](https://netlify.com) → **Add new site** → **Import from GitHub**
2. Choisis le repo `Site-portfolio`
3. Netlify lit automatiquement `netlify.toml` (dossier `portfolio/`)
4. **Deploy** → renomme le site en `ryan-jaspart` (URL : `ryan-jaspart.netlify.app`)

## Formulaire contact

Compte [formspree.io](https://formspree.io) — ID déjà configuré dans `index.html`.

## Lancer en local

Ouvrir `index.html` dans le navigateur.
