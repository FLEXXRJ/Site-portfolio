# Portfolio — Ryan Jaspart

Site vitrine one-page pour présenter mes services de développement web freelance.

## Stack

- HTML5
- CSS3 (Flexbox, responsive)
- JavaScript (validation formulaire, menu mobile, scroll fluide)

## Fichiers

- `portfolio.html` — structure
- `portfolio.css` — styles
- `portfolio.js` — interactions
- `favicon.svg` — icône du site
- `pain-dore.png` — capture du projet boulangerie (carte projets)
- `Portfolio.png` — capture de ce portfolio (carte projets)

## Formulaire contact

1. Créer un compte sur [formspree.io](https://formspree.io)
2. Créer un formulaire et copier l'ID (ex. `xyzabcde`)
3. Remplacer `VOTRE_ID` dans `portfolio.html` :
   `action="https://formspree.io/f/xyzabcde"`

## Lancer en local

Ouvrir `portfolio.html` dans le navigateur, ou avec Live Server.
