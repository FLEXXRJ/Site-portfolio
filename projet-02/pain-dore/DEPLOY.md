# Déploiement — Le Pain Doré

## Netlify (glisser-déposer)

1. Va sur [app.netlify.com/drop](https://app.netlify.com/drop)
2. Glisse le dossier `pain-dore/` entier (avec index.html, style.css, histoire.html…)
3. Une fois en ligne, va dans **Site configuration** → **Domain management** → **Options**
4. Renomme le site en **`le-pain-dore`** → URL : `https://le-pain-dore.netlify.app`

Cette URL est déjà utilisée dans le portfolio (lien « Voir le site » sur la carte Pain Doré).

## Fichiers du site

- `index.html` — accueil
- `histoire.html` — notre histoire
- `style.css` — styles partagés
- `script.js` — menu mobile, scroll, animations
